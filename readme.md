# Student Message dApp

## Project Description
Student Message dApp is a simple decentralized application built using Solidity and the Ethereum Sepolia test network.

It allows users to store, view, update, and clear a message through a smart contract.

## Technologies Used
- Solidity
- Remix IDE
- Ethereum Sepolia Testnet
- MetaMask
- HTML
- CSS
- JavaScript
- ethers.js

## Smart Contract Features
1. `setMessage()` – Stores or updates a message.
2. `getMessage()` – Reads the currently stored message.
3. `getOwner()` – Displays the smart contract owner's address.
4. `clearMessage()` – Clears the stored message.

## How to Use
1. Open the website.
2. Click Connect MetaMask.
3. Make sure MetaMask is connected to Sepolia.
4. Enter a message.
5. Click Save Message and confirm the transaction.
6. Click Read Message to view the stored message.
